EV Charging Pricing Analysis
Project Overview

This project analyzes EV charging prices across major charging operators in South Korea.

The goal of the project is to build an end-to-end data analytics workflow, covering data collection, data cleaning, SQL and Python analysis, visualization, and cloud-based data management.

Pricing data from six EV charging operators was collected and standardized to compare pricing differences by operator, charger type, power band, and customer type.

The final workflow covers:

* Web crawling with Python
* Data cleaning and transformation with Pandas
* SQL analysis using PostgreSQL and BigQuery
* Data visualization with Power BI
* Cloud storage and analytics using Google Cloud Platform
